# Value Growth Score — Flint Consulting

Diagnóstico de 49 preguntas que calcula el Value Growth Score (0–100), el score por cada uno de los 8 componentes de valor y una estimación de valor con múltiplos de EBITDA de la industria.

- Un solo `index.html` autocontenido, publicado en GitHub Pages.
- Funciona como lead magnet: el resultado sólo se muestra después de que Web3Forms confirma el envío de los datos de contacto (llegan a connect@flintconsulting.mx).
- Preguntas, pesos, componentes y múltiplos viven en el JSON `#vg-data` dentro del HTML.
